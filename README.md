# منظومة كشف الاستلال العلمي والمراجعة الأكاديمية (Arabic Academic Plagiarism Detector)

منظومة متطورة ومحلية بالكامل (**100% Offline**) لفحص ومراجعة النزاهة الأكاديمية في الرسائل والأبحاث العلمية المكتوبة باللغة العربية، ومقارنتها بقاعدة بيانات مرجعية محلية. صُممت المنظومة لتعمل بكفاءة عالية على الحواسيب المكتبية المتوسطة والاقتصادية بنظام **Windows** معتمدة على المعالج المركزي (**CPU-Only**) دون الحاجة إلى معالجات رسومية خارقة (GPU) أو اتصال بالإنترنت.

├── app/                                   # طبقة تطبيق الويب والخدمات
│   ├── models/schema.py                   # جداول SQLAlchemy (المستندات، الصفحات، المقاطع، التقارير، المستخدمين)
│   ├── repositories/                      # طبقة الوصول للبيانات (Document, Report, User Repos)
│   ├── services/                          # منطق الأعمال (Scan, Paper, Settings, System Services)
│   └── routes/                            # نقاط النهاية (Auth, Papers, Scans, Reports, Settings, System)

├── plagiarism_detector/                   # النواة الخوارزمية المستقلة
│   ├── extraction/                        # استخراج النصوص بحسب الصفحات (PyMuPDF, DOCX) و OCR مشروط
│   ├── preprocessing/                     # التطبيع العربي الثنائي (خفيف/مشكوك)، التقطيع، وكشف التلاعب

│   ├── detection/                         # خط أنابيب الكشف متعدد المراحل (Index, Shingles, TF-IDF, Semantic)

## 🚀 خط أنابيب الكشف متعدد المراحل (Multi-Stage Detection Pipeline)

للتخلص من التعقيد الحسابي الثنائي $O(N \times M)$ عند مقارنة أبحاث ضخمة، تطبق المنظومة خط أنابيب هرمي:

1. **فهرس مقلوب فائق السرعة (Inverted Index Candidate Retriever):**
   استرجاع مقاطع المرشحين الأعلى احتمالية في أجزاء من الثانية دون استهلاك موارد المعالج.
2. **المرحلة الأولى - النسخ الحرفي وشبه الحرفي (Stage A - Shingles & Jaccard Matcher):**
   تقسيم النص إلى حزم كلمات خماسية (5-grams Shingles) وحساب معامل جاكارد ونسبة التطابق التسلسلي الدقيق (SequenceMatcher).
3. **المرحلة الثانية - إعادة الصياغة اللفظية (Stage B - Word & Char N-Gram TF-IDF):**
   توليد متجهات TF-IDF للكلمات ومتجهات الأحرف المورفولوجية (`char_wb`) لقياس تشابه جيب التمام (Cosine Similarity) وكشف التغييرات النحوية واللواحق.
4. **المرحلة الثالثة - إعادة الصياغة الدلالية الاختيارية (Stage C - CPU Semantic Embeddings):**
   تفعيل اختياري لنموذج التضمين الخفيف السريع على المعالج بدون استهلاك الذاكرة.

## 📖 تمييز التوثيق، الاقتباس، وأرقام الصفحات المصدرية

- **إسناد أرقام الصفحات بدقة (Source Page Attribution):**
  يستخرج محرك `PyMuPDF` النصوص لكل صفحة على حدة (1-indexed)، مما يسمح للتقرير بإظهار أرقام الصفحات المستل منها في المستند الأصلي (مثل: `ص. 14، 25` أو `صفحات غير مرقمة / DOCX`).
- **حساب الحجم المقتبس وحد الـ 5 صفحات:**
  حساب عدد الصفحات المستلة بناءً على معيار 250 كلمة/صفحة، وإطلاق تنبيه أكاديمي بارز عند تجاوز أي بحث مفرد للاقتباس المسموح به (5 صفحات فأكثر).
- **وعي الاقتباس واستبعاد المراجع:**
  - التمييز التلقائي بين **نسبة الاستلال الإجمالية (Total Similarity)** و**نسبة الاستلال الإشكالية (Problematic Similarity)**.
  - استبعاد النصوص بين علامات التنصيص المتبوعة بتوثيق أكاديمي `(اسم الباحث، السنة، ص. س)`.
  - استبعاد قسم قائمة المراجع والمصادر (Bibliography) في نهاية الرسائل لعدم احتسابها كاستلال احتيالي.

## 🛡️ كشف أساليب التلاعب والتحايل (Anti-Cheating Engine)

تكشف المنظومة محاولات خداع البرمجيات الأكاديمية:
- **المسافات الصفرية الخفية (Zero-Width Spaces):** كشف وحذف محارف `\u200B` و `\u200C` و `\uFEFF` المستخدمة لكسر الكلمات.
- **الحروف اللاتينية والسيريلية المزروعة (Homoglyphs):** كشف الأحرف البديلة الشبيهة بصرياً بحروف الضاد والعين والألف والميم، وتصحيحها قبل الفحص.
- **التطويل الزائد (الكشيدة):** إزالة محارف التطويل `ـ` غير المعيارية.

## 🤖 مؤشرات الذكاء الاصطناعي والتنويه العلمي (AI Writing Indicators)

تتضمن المنظومة محلل مؤشرات أسلوبية محلي (Stylistic Indicators) يدرس تكرار الكلمات، تنوع المفردات، وانتظام أطوال الجمل.
> [!IMPORTANT]
> **تنويه أكاديمي ملزم:** درجات كشف الذكاء الاصطناعي هي مؤشرات استرشادية لخصائص الأسلوب الإحصائي وليست دليلاً قطعياً على التوليد الآلي، ولا يجوز الاستناد إليها منفردة دون مراجعة بشرية متخصصة ومناقشة علمية مع الباحث.

## 🔒 أمان النظام وإدارة المستخدمين (Security & Roles)

- استبدال التشفير الثابت بـ **bcrypt** المعياري بـ 12 دورة تمليح (Salt Rounds).
- التخلص التام من أي بيانات دخول ثابتة مسبقاً (Hardcoded Credentials).
- **التهيئة لأول مرة (First-Time Setup):** إذا كانت قاعدة البيانات جديدة، يطلب النظام تلقائياً تعيين حساب المدير للمرة الأولى.
- **تدرج الصلاحيات:**
  - **مدير النظام (Admin):** إدارة الموظفين، ضبط الحساسية، مراجعة طابور الفحص الأولي، القبول المبدئي، والاعتماد النهائي.
  - **موظف الفحص (Employee):** رفع الأبحاث وإجراء الفحص وإرسال التقارير للاعتماد فقط.

## 💻 متطلبات التشغيل والتثبيت

### 1. المتطلبات الدنيا (Low-to-Mid Range PCs)
- **نظام التشغيل:** Windows 10 أو Windows 11 (64-bit).
- **المعالج:** معالج ثنائي أو رباعي النواة (Intel Core i3 / i5 أو AMD Ryzen 3).
- **الذاكرة العشوائية (RAM):** 4 جيجابايت كحد أدنى (يوصى بـ 8 جيجابايت).
- **بيئة التشغيل:** Python 3.10 فأحدث.
- **الإنترنت:** **غير مطلوب إطلاقاً (100% Offline)**.

### 2. التثبيت والتشغيل المحلي
```powershell
# تثبيت الحزم الأساسية
pip install -r requirements.txt

# تشغيل الخادم المحلي
python server.py
```
ثم افتح المتصفح على العنوان المحلي: `http://localhost:5000` أو `http://127.0.0.1:5000`.

## 🌐 التجهيز المعماري للشبكة المحلية (LAN Deployment Preparation)

تم تصميم المنظومة لتعمل حالياً كجهاز منفرد، مع إمكانية تحويلها مستقبلاً إلى خادم مركزي على الشبكة المحلية دون إعادة كتابة المنطق:
1. تغيير مسار `DATABASE_URL` في `config.py` إلى عنوان خادم PostgreSQL أو مسار SQLite شبكي مشترك.
2. تعديل متغير `HOST = "0.0.0.0"` للسماح لأجهزة الحاسب الأخرى على نفس الشبكة المحلية بالدخول عبر المتصفح باستخدام عنوان IP الخاص بالجهاز الرئيسي (مثال: `http://192.168.1.100:5000`).
