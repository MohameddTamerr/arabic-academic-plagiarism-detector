# كاشف الانتحال الأكاديمي العربي

أداة مكتبية أوفلاين لكشف الانتحال في الأبحاث العربية، مبنية بالكامل بـ Python وتعمل على أي جهاز ضعيف بدون إنترنت.

---

## المميزات الرئيسية

| الميزة | التفاصيل |
|--------|----------|
| كشف النسخ الحرفي | مطابقة دقيقة للجمل حتى مع لعب الهمزات (أ/إ/آ/ء) والتشكيل |
| كشف إعادة الصياغة | TF-IDF على مستوى الجملة لاكتشاف نفس المعنى بكلمات مختلفة |
| تطبيع ومعالجة النصوص العربية | يكشف كل محاولات التلاعب بالهمزات والتاء المربوطة والألف المقصورة |
| قاعدة بيانات محلية (SQLite) | SQLite — تخزين الـ1000 بحث المصدرية محليًا |
| فهرسة سريعة للبيانات | يُبنى مرة واحدة ويُستخدم لأي عدد من الفحوصات |
| تقرير تحليلي مفصل | نسب مئوية + نص ملوَّن + جدول المصادر |
| تصدير التقارير (HTML) | تقرير جاهز للطباعة أو الإرسال |
| يعمل بدون إنترنت (100% Offline) | لا يحتاج إنترنت بعد التثبيت الأول |

## دليل الاستخدام

### 1. إضافة الأبحاث المصدرية (مرة واحدة)
1. افتح تبويب **قاعدة الأبحاث**
2. اضغط **إضافة مجلد كامل** واختر مجلد الـ1000 بحث
3. انتظر اكتمال الاستيراد
4. اضغط **إعادة بناء الفهرس** (مرة واحدة بعد أي إضافة)

### 2. فحص بحث جديد
1. افتح تبويب **فحص بحث جديد**
2. اضغط **اختيار ملف للفحص** أو الصق النص مباشرة
3. اضغط **بدء الفحص**
4. انتقل لتبويب **نتيجة الفحص** لرؤية النتائج

### 3. قراءة التقرير
- **أحمر** = نسخ حرفي (مع % التطابق واسم المصدر)
- **برتقالي** = إعادة صياغة محتملة
- ⬜ **أبيض** = نص أصلي
- جدول المصادر يعرض أعلى نسبة تطابق مع كل بحث مصدر
- اضغط **حفظ التقرير HTML** للحصول على ملف جاهز للطباعة

## الخوارزميات المستخدمة

### كشف النسخ الحرفي
- تقطيع الجملة لـ shingles (n-grams بحجم 5 كلمات)
- مقارنة بـ **Jaccard similarity** على مستوى الجملة
- عتبة الكشف: `≥ 35%` (قابلة للضبط في `detector.py`)

### كشف إعادة الصياغة
- **TF-IDF Vectorizer** على مستوى الجملة
- **Cosine Similarity** بين جملة البحث الجديد وكل الجمل المصدرية
- عتبة الكشف: `≥ 60%` (قابلة للضبط في `detector.py`)

## ضبط حساسية الكشف

افتح `plagiarism_detector/core/detector.py` وعدّل:
```python
SHINGLE_SIZE           = 5    # حجم مجموعة الكلمات المقارَنة (أكبر = أقل حساسية)
JACCARD_COPY_THRESHOLD = 0.35 # عتبة النسخ الحرفي (أعلى = أقل نتائج إيجابية)
COSINE_PARA_THRESHOLD  = 0.60 # عتبة إعادة الصياغة (أعلى = أقل نتائج إيجابية)
```
