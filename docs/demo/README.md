# دليل تصوير وتسجيل العرض التجريبي (System Demo Video Guidelines)

يوضح هذا الدليل الخطوات والإرشادات الموصى بها لتسجيل فيديو توضيحي (Demo Video) عملي وموجز (مدة 2 إلى 4 دقائق) لمنظومة **فاحص الانتحال والتشابه الأكاديمي العربي (Arabic Academic Plagiarism Detector)**، لاستخدامه في العروض التقديمية والتوثيق الأكاديمي والمؤسسي.

---

## 1. أهداف العرض التجريبي (Demo Objectives)
- إبراز سهولة تشغيل المنظومة بنقرة واحدة (بدون سطر أوامر).
- إظهار الواجهة الرسومية الحديثة وسلاسة الاستخدام للمراجعين.
- استعراض دورة الفحص المتكاملة من الرفع حتى التقرير المعتمد.
- التأكيد على عمل المنظومة محلياً بنسبة 100% في بيئة معزولة عن الإنترنت (100% Offline / Air-Gapped).

---

## 2. التسلسل الزمني المقترح للتسجيل (2–4 دقائق)

| التوقيت التقريبي | المشهد / الشاشة | الإجراء المشروح |
| :--- | :--- | :--- |
| **0:00 – 0:30** | سطح المكتب / مجلد الحزمة المحمولة | النقر المزدوج على `Start-System.bat`، ظهور شاشة الجاهزية (`SYSTEM READY`) والفتح التلقائي للمتصفح على الواجهة الرسومية. |
| **0:30 – 0:50** | شاشة تسجيل الدخول | تسجيل الدخول بحساب مراجع معتمد (`Reviewer`) أو مسؤول (`Admin`) واستعراض لوحة المؤشرات الرئيسية. |
| **0:50 – 1:20** | صفحة فحص بحث جديد | رفع مستند بحثي (PDF أو DOCX)، إدخال العنوان واسم الباحث، وبدء عملية الفحص وإظهار شريط التقدم اللحظي. |
| **1:20 – 2:10** | تقرير فحص الانتحال التفاعلي | فتح التقرير المكتمل، استعراض نسبة التشابه الإجمالية، تفاصيل المصادر المرجعية المطابقة، تلوين المقاطع المتشابقة جنباً إلى جنب، وتحليل الاستشهادات وقائمة المراجع. |
| **2:10 – 2:40** | مسار المراجعة والاعتماد البشري | استعراض حالة المراجعة، إضافة ملاحظات المحكّم الأكاديمي، واعتماد القرار (المراجعة البشرية الإلزامية). |
| **2:40 – 3:15** | الأدوات التشغيلية والصيانة | استعراض سريع لنوافذ `Check-System.bat` (فحص سلامة النظام) و `Backup-System.bat` (النسخ الاحتياطي الفوري) و `View-Logs.bat`. |
| **3:15 – 3:30** | الختام | التأكيد على أن المنظومة تعمل بالكامل محلياً على الشبكة الداخلية دون أي حاجة للإنترنت أو الخدمات السحابية. |

---

## 3. إرشادات التسجيل الفني
1. **دقة الشاشة الموصى بها**: 1920×1080 (Full HD) بنسبة أبعاد 16:9.
2. **البيانات المستخدمة**: يُنصح باستخدام مستندات أكاديمية تجريبية عامة ومصرح بنشرها، وتجنب استخدام أبحاث حقيقية خاصة أو بيانات شخصية سرية.
3. **تطبيق الرابط في التوثيق**:
   بعد رفع الفيديو على المنصة المعتمدة (مثل YouTube أو Google Drive أو الخادم الداخلي)، يتم استبدال الرمز النائب في ملف `README.md`:
   ```markdown
   [شاهد العرض التجريبي](DEMO_URL_HERE)
   ```
   برابط الفيديو المباشر.
