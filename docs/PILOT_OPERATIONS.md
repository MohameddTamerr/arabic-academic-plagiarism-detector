# دليل العمليات التشغيلية والحوكمة للمرحلة التجريبية (Pilot Operations & Governance Protocol)
## Arabic Academic Plagiarism Detector — Release v1.0.0-rc2

---

### 1. بيئة التشغيل منخفضة الموارد (Low-Resource Operating Profile)

تمت هندسة المنظومة للعمل بكفاءة تامة على خادم محلي مفرد بمواصفات عادية:
- **المعالج (CPU):** معالج عادي رباعي النواة (CPU-Only، لا يلزم وجود GPU).
- **الذاكرة (RAM):** 8 جيجابايت كافية لمعالجة الفحوصات وإدارة الفهارس المعجمية في الذاكرة.
- **التخزين (Disk):** مساحة كافية لقاعدة بيانات SQLite وملفات الأبحاث مع حدود قصوى موصى بها ($\le 10\text{ GB}$).
- **التزامن المحدد (Concurrency Bounds):**
  - الحد الأقصى للفحوصات المتزامنة: `MAX_CONCURRENT_SCANS = 2`.
  - الحد الأقصى لمعالجة OCR المتزامنة: `MAX_CONCURRENT_OCR_JOBS = 1` (بقفل عبر العمليات).

---

### 2. بروتوكول النسخ الاحتياطي قبل بدء التجربة (Pre-Pilot Backup Protocol)

قبل البدء باستقبال أبحاث المرحلة التجريبية، يتعين على المشرف الفني تنفيذ إجراءات النسخ الاحتياطي الشاملة:
1. أخذ نسخة احتياطية كاملة لقاعدة البيانات والتخزين وسجل الكتالوج:
   ```powershell
   python -c "from app.services.backup_service import create_backup; print(create_backup(label='Pre_Pilot_Baseline'))"
   ```
2. التحقق من سلامة الأرشيف واحتساب بصمة التجزئة SHA-256.
3. حفظ نسخة من الأرشيف على وسيط تخزين خارجي معزول (Offline External Storage).
4. **سياسة عدم النشر السحابي:** يُحظر رفع أو نسخ قواعد البيانات أو أبحاث الطلاب إلى أي خدمات سحابية عامة.

---

### 3. سياسة الاحتفاظ بالبيانات والخصوصية (Pilot Data Retention Policy)

- **ملفات الأبحاث المرفوعة:** تُحفظ محلياً في مجلد `storage/research` وتخضع لسياسة الاحتفاظ الأكاديمي المعتمدة بالجامعة (مثال: الحفظ لمدة فصل دراسي واحد أو سنتين للأطروحات).
- **ملفات الاستخراج المؤقتة:** تُحذف تلقائياً فور اكتمال الفحص.
- **سجلات التدقيق (Audit Logs):** غير قابلة للتعديل أو الحذف، وتُحفظ كمرجع إثبات إجرائي للعمليات.
- **خصوصية سجلات النظام (Logging Privacy):** السجلات البرمجية لا تحتوي على نصوص الأبحاث الكاملة، أو كلمات المرور، أو رموز الجلسات، أو البيانات الشخصية، وتكتفي بمعرفات الأبحاث ورموز الأخطاء.
