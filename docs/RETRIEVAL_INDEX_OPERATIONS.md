# الدليل التشغيلي لإدارة وبناء فهرس الاسترجاع (Retrieval Index Operations & Governance)

---

## 1. ربط الفهرس بحوكمة قاعدة المراجع (Corpus Version Coupling)

يرتبط فهرس الاسترجاع بصورة وثيقة وحتمية مع إصدار قاعدة المراجع المعتمدة (`ReferenceCorpusVersion`):
1. **بيان الفهرس (Index Manifest - `index_manifest.json`):**
   - يتضمن: `index_version`، `corpus_version`، `fingerprint`، عدد المستندات، عدد المقاطع، وتاريخ البناء.
2. **الحالة التلقائية (Stale vs Current):**
   - عند إضافة أو تعطيل أو استبدال أي مرجع، يتحول مؤشر الفهرس إلى `stale`.
   - تُحدَّث بيانات الفهرس ذرياً (Incremental Indexing) أو يُعاد بناؤه تلقائياً ليصبح `current`.
   - تمنع سياسة الفحص الآمنة الفحص ضد فهرس تالف أو غير متطابق.

---

## 2. البناء المحصن ضد الانهيار (Crash-Safe Index Build & Promotion)

- **البناء في مجلد مؤقت معزول:** يُبنى الفهرس الجديد داخل مسار `_build_<uuid>`.
- **التحقق من السلامة واكتمال الملفات:** التأكد من قراءة وتطابق كافة القوائم المقلوبة واحتساب بصمة التجزئة SHA-256 للبيان.
- **الاستبدال الذري (Atomic Promotion):** نقل المجلد المكتمل ذرياً عبر `os.replace()` ليحل محل الفهرس القديم في خطوة واحدة، مما يمنع تشوه الفهرس في حال انقطاع التيار أو إيقاف الخادم.

---

## 3. أداة إعادة بناء الفهرس (Index Rebuild CLI)

```powershell
# إعادة بناء الفهرس لأحدث إصدار معتمد لقاعدة المراجع
python tools/rebuild_retrieval_index.py

# إعادة البناء مع المحاكاة
python tools/rebuild_retrieval_index.py --dry-run
```
