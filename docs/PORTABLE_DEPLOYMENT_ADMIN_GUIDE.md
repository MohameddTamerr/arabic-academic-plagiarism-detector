## 1. نظرة عامة والمعمارية المستهدفة (System Architecture)

تم تصميم الحزمة المحمولة لتعمل بنمط **التوزيع المستقل المعزول بالكامل (100% Self-Contained Offline Deployment)**. لا تتطلب المنظومة تثبيت أي برمجيات أو خوادم مسبقة (مثل Python أو PostgreSQL أو Node.js).

```
              Ministry LAN (الشبكة الداخلية للكلية)
                               |
       +-----------------------+-----------------------+
       |                       |                       |
   جهاز فاحص 1             جهاز فاحص 2             جهاز فاحص N
   (متصفح Web)             (متصفح Web)             (متصفح Web)
       |                       |                       |
       +-----------------------+-----------------------+
                               |
           الجهاز المركزي للكلية / الخادم المحلي (Central PC)
                               |
                  [ خادم التطبيق المحلي Waitress ]
                               |
               +---------------+---------------+
               |                               |
       [ قاعدة بيانات SQLite WAL ]       [ مستودع الملفات CAS ]
       (على القرص المحلي الحصري)           (Storage/finalized/)
               |                               |
               +---------------+---------------+
                               |
                     [ عمال الفحص الخلفي ]
                     (Scan Workers x 2..4)
```

> [!IMPORTANT]
> **قاعدة تخزين قاعدة البيانات المحلية:**  
> يجب أن تظل قاعدة بيانات `papers.db` على **القرص الصلب المحلي المباشر** للجهاز المركزي (Local SSD/HDD). يمنع منعاً باتاً وضع ملف قاعدة البيانات مباشرة على مجلد مشاركة شبكي (SMB Share / NAS / Windows Shared Folder) تجنباً لمشاكل أقفال الشبكة في SQLite.

## 3. إعدادات الشبكة المحلية وجدار الحماية (LAN & Windows Firewall)

تدعم المنظومة نمطين صريحين للتشغيل عبر ملف `Config/system_config.json`:
1. **النمط المحلي الحصري (`mode: "local"`):** يستمع الخادم على `127.0.0.1` ولا يمكن الوصول إليه إلا من نفس الجهاز.
2. **نمط الشبكة المحلية للمؤسسة (`mode: "lan"`):** يستمع الخادم على واجهة الشبكة الداخلية `0.0.0.0` مما يتيح للأجهزة المصرح لها في نفس الكلية الاتصال بالمنظومة عبر المتصفح.

### أمر فتح المنفذ في جدار حماية ويندوز (Windows Firewall Inbound Rule):
للسماح للأجهزة الأخرى في الكلية بالوصول للمنظومة على المنفذ `5000`، ينفذ مسؤول النظام الأمر التالي لمرة واحدة في موجه أوامر المسؤول (PowerShell as Administrator):

```powershell
New-NetFirewallRule -DisplayName "Arabic Plagiarism Detector LAN" `
                    -Direction Inbound `
                    -LocalPort 5000 `
                    -Protocol TCP `
                    -Action Allow `
                    -Profile Private,Domain
```

> [!CAUTION]
> **قاعدة أمان جدار الحماية:**  
> لا تقم أبداً بتعطيل جدار حماية ويندوز بالكامل. تقتصر القاعدة فقط على المنفذ `5000` للشبكات الخاصة/النطاق الداخلي (Private/Domain Profile).

## 4. تجربة التشغيل الأول وتأمين مدير النظام (First-Run & Admin Bootstrap)

عند تشغيل المنظومة لأول مرة على قاعدة بيانات نظيفة:
1. يتم إنشاء الجداول والفهارس الـ 140 تلقائياً.
2. توجه الواجهة المستخدم فوراً إلى **شاشة إنشاء مدير النظام الأول (First Admin Setup)**.
3. يقوم مسؤول الكلية بإدخال اسم المستخدم وكلمة المرور الخاصة به.
4. بمجرد إنشاء الحساب الأول، يتم إغلاق نقطة التهيئة الأولى نهائياً للأبد لمنع أي محاولة تجاوز.
5. **انعدام كلمات المرور الافتراضية:** لا تتضمن المنظومة أي كلمة مرور افتراضية أو حساب مخفي.

## 5. العمليات اليومية والأدوات التلقائية (Operations Guide)

| الأداة / الملف | الوظيفة والإجراءات المنفذة |
| :--- | :--- |
| **`Start-System.bat`** | 1. التحقق من المساحة الحرة للقرص.<br>2. منع التكرار (Single Instance Lock).<br>3. تشغيل خادم Waitress و 2 عمال فحص.<br>4. فحص الجاهزية عبر `/api/system/ping`.<br>5. فتح المتصفح وعرض عناوين Local و LAN. |
| **`Stop-System.bat`** | 1. تفعيل وضع التجفيف (Drain Mode) للعمال لإنهاء المهام النشطة.<br>2. حفظ المهام المعلقة في الطابور.<br>3. إيقاف خادم الويب بأمان.<br>4. دمج معاملات WAL تلقائياً (`PRAGMA wal_checkpoint(TRUNCATE)`). |
| **`Backup-System.bat`** | 1. تنفيذ نسخ احتياطي حي عبر `sqlite3.backup` غير الحاجب للقراءة.<br>2. حساب بصمة SHA-256 للنسخة.<br>3. فحص سلامة الهيكل `PRAGMA integrity_check`.<br>4. حفظ ملف المانيفست `backup_YYYYMMDD_HHMMSS_manifest.json`. |
| **`Restore-System.bat`** | 1. عرض النسخ المتوفرة والتحقق من بصمة وسلامة النسخة المختارة.<br>2. أخذ نسخة وقائية فورية من قاعدة البيانات الحالية قبل الاستبدال.<br>3. استبدال الملف وإعادة الفحص والتحقق. |
| **`Check-System.bat`** | تقرير شامل لحالة الخدمة، قاعدة البيانات، النزاهة الهيكلية، المساحة الحرة، الذاكرة، طابور المهام، وعناوين الشبكة. |

## 7. القيود العلمية والمسؤولية الأكاديمية (Scientific Boundaries)

- **التحكيم البشري الإلزامي:** المنظومة أداة إلكترونية مساعدة لحساب نسب ومواضع التشابه الحرفي وإعادة الصياغة، ولا تعد بديلاً عن القرار الأكاديمي البشري الصادر عن لجان المناقشة والتحكيم المعتمدة.
- **التعرف الضوئي OCR:** مخصص للنصوص الممسوحة ضوئياً ويتطلب توافر محرك Tesseract محلياً، بينما تعمل ملفات PDF الرقمية والأبحاث العادية بكفاءة تامة 100% دون الحاجة لـ OCR.
- **الخصوصية والعزل التام:** لا تقوم المنظومة بإرسال أي نصوص أو بيانات إلى خارج الجهاز أو الشبكة المحلية، ولا تتصل بأي خدمات سحابية على الإطلاق.
