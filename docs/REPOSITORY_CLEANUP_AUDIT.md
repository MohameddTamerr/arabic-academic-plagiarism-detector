# تقرير تدقيق وهيكلة ملفات المستودع (Repository Cleanup Audit)

يوثق هذا المستند التدقيق الشامل لكافة مكونات وملفات مستودع **فاحص الانتحال الأكاديمي العربي (Arabic Academic Plagiarism Detector)**، وتصنيفها المنهجي وفق المعايير المؤسسية المعتمدة وضوابط الأمان، وتحديد الملفات المحتفظ بها وتلك التي تم تنظيفها أو استبعادها من التتبع في Git.

---

## 1. تصنيف الملفات المنهجي (File Categorization)

| الفئة (Category) | الوصف | الإجراء المتبع |
| :--- | :--- | :--- |
| **A. REQUIRED FOR RUNTIME** | ملفات الشيفرة البرمجية الأساسية، النماذج، والخدمات، والواجهات | الاحتفاظ الكامل والتتبع في Git |
| **B. REQUIRED FOR BUILD/DEPLOYMENT** | مشغلات Windows الدفعية، نصوص البناء، وأدوات التشغيل المحمولة | الاحتفاظ الكامل والتتبع في Git |
| **C. REQUIRED FOR TESTS** | حزم الاختبارات الآلية، بيئات الفحص المعزولة، والمطابقات | الاحتفاظ الكامل والتتبع في Git |
| **D. REQUIRED DOCUMENTATION** | أدلة الاستخدام، التوثيق الإداري، تقارير المقاييس، وبيانات الإصدار | الاحتفاظ الكامل والتتبع في Git |
| **E. DEVELOPMENT / DEBUG ONLY** | سكربتات التطوير والتحليل المؤقتة وفحوصات سريعة | الاحتفاظ محلياً في `scratch/` واستبعادها من Git |
| **F. GENERATED ARTIFACT** | مخرجات البناء، الحزم التشخيصية، ومجلدات الكاش | استبعاد تام عبر `.gitignore` |
| **G. SENSITIVE / MUST NEVER BE COMMITTED** | قواعد البيانات (`.db`)، السجلات (`.log`)، النسخ الاحتياطية، والأسرار | استبعاد قطعي عبر `.gitignore` |
| **H. UNCERTAIN — KEEP** | أي ملف غير متأكد من فائدته التراكمية | الاحتفاظ به وعدم حذفه |

## 3. إثبات أمان التنظيف وعدم تأثر وظائف النظام
- تم التأكد من أن نقل الملفات الوسيطة (`scratch_test_retrieval.py`, `improved_retrieval_benchmarks.json`, `queue_benchmark_results.json`, `retrieval_benchmark_results.json`) إلى مجلد `scratch/` لا يؤثر إطلاقاً على أي من مسارات التشغيل أو الاختبارات الآلية (`pytest`).
- تم التأكد من استبعاد كافة قواعد البيانات والملفات المؤقتة والسجلات من التتبع في Git لمنع رفع أي بيانات خاصة أو أسرار.
