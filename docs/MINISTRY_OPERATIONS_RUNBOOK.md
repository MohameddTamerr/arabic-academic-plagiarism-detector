# دليل التشغيل والصيانة الوزارية (Ministry Operations & Administration Runbook)
## منظومة كاشف السرقات العلمية الأكاديمي للنصوص العربية — الإصدار v1.4.0-rc

---

## 1. الإجراءات التشغيلية اليومية والدورية (Daily & Periodic Procedures)

### 1.1 تشغيل وإدارة عمال المعالجة (Worker Management)
- **تشغيل عامل فحص عادي:**
  ```bash
  python tools/run_worker.py --worker-id worker_scan_01 --capabilities SCAN
  ```
- **تشغيل عامل مخصص لإعادة بناء الفهارس:**
  ```bash
  python tools/run_worker.py --worker-id worker_rebuild_01 --capabilities INDEX_BUILD
  ```
- **تفريغ العامل بأمان قبل الصيانة (DRAIN Mode):**
  يتم إرسال إشارة التفريغ عبر واجهة المشرف أو عبر سطر الأوامر؛ حيث يمتنع العامل عن سحب أي مهام جديدة ويكمل المهمة الحالية قبل الإغلاق التام.

### 1.2 النسخ الاحتياطي الدوري والتحقق (Periodic Backup)
- **تنفيذ نسخة احتياطية فورية كاملة:**
  ```bash
  python -c "import app.services.backup_service as bs; res = bs.create_full_backup(); print('Backup Result:', res)"
  ```
- **فحص صحة النسخ الاحتياطية المجدولة:**
  يتم فحص حقل `backup_freshness` في واجهة مراقبة صحة النظام للتأكد من عدم تجاوز النسخ الاحتياطي 24 ساعة.

### 1.3 إعادة بناء وتحديث الفهرس المرجعي الأكاديمي (Index Operations)
- عند اعتماد وتفعيل نسخة مرجعية جديدة من الأبحاث:
  ```bash
  python tools/rebuild_retrieval_index.py --force
  ```

## 2. إجراءات التعامل مع الحالات الطارئة (Emergency Troubleshooting)

| العَرَض التشغيلي | السبب المحتمل | الإجراء التصحيحي المعتمد |
| :--- | :--- | :--- |
| **تراكم كبير في طابور المهام (`queue backlog`)** | نقص في عدد العمال المشغلين أو إيقافهم | تشغيل عمال إضافيين (حتى 4 عمال كحد أمثل لـ SQLite) ومراجعة سجلات العمال |
| **مهام عالقة في حالة `PROCESSING`** | انهيار مفاجئ لعملية العامل أو انقطاع التيار | تشغيل أداة الاسترداد الذري: `python tools/recover_stale_jobs.py` |
| **تحذير انخفاض مساحة القرص (<10GB)** | تراكم الملفات المؤقتة أو تضخم السجلات | تدوير سجلات النظام القديمة وإفراغ مساحات التجهيز المؤقتة `staging` |
| **خطأ عدم تطابق بصمة التخزين `HASH_MISMATCH`** | تلاعب خارجي أو تلف في قطاعات القرص | فحص سجلات التدقيق، عزل الكائن التالف، واستعادته من النسخة الاحتياطية |
