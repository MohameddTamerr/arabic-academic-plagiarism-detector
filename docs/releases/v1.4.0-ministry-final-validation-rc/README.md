# وثيقة الإصدار: Release v1.4.0-ministry-final-validation-rc
## مرشح الإطلاق النهائي المصلد للبيئة الوزارية المعزولة (Ministry-Scale Offline Hardened Release Candidate)

---

## 1. ملخص الإصدار (Release Overview)

يمثل الإصدار **`v1.4.0-ministry-final-validation-rc`** النسخة النهائية المكتملة والمصلدة لمسار التحول الوزاري (Ministry Roadmap — Prompt 4)، حيث يجمع كافة ركائز الأمان الصارم، والتعافي من الكوارث، والنسخ الاحتياطي المعاملاتي، والجاهزية للبنى التحتية عالية التوافر، مع إجراء تدريبات استعادة حقيقية واختبارات إجهاد وسعة تحت ضغط العمل الموزع.

- **معرف الإصدار:** `v1.4.0-ministry-final-validation-rc`
- **إصدار التطبيق:** `2.7.0`
- **إصدار محرك الفحص:** `1.5.0`
- **محرك طابور المهام:** `DatabaseJobQueue` الموزع المقاوم للاختناق
- **إصدار بروتوكول العامل:** `1.4.0`
- **محرك التخزين الافتراضي:** `filesystem_cas` (Content-Addressed Storage)
- **محرك الاسترجاع:** `LocalDiskRetrievalIndex` ثنائي المرحلة مع سقف $K \le 50$
- **بيئة التشغيل:** معزولة هوائياً 100% (100% Air-Gapped / Zero-Cloud / Zero-Telemetry)
