## 2. التحسينات الخوارزمية المعتمدة (Integrated Production Enhancements)

1. **الاسترجاع المطور ثنائي القناة (EXP-01 Dual-Channel Candidate Retrieval):**
   - الجمع بين الكلمات النادرة والمتواليات المورفولوجية للحروف (Char 3-grams).
   - قفزة في استرجاع المرشحين Recall@10 من 52.8% إلى 93.1% على البيانات المحجوبة.
   - قابل للرجوع الفوري عبر راية `'candidate_retrieval_mode': 'baseline'`.
2. **استبعاد النصوص المؤسسية على مستوى المقاطع (EXP-03 Span-Level Common-Text Filter):**
   - استبعاد الديباجات والكليشيهات مع الحفاظ الكامل على المقاطع المنسوخة الموضوعية (0 سلبيات زائفة).
   - خفض التداخل الزائف من 44.0% إلى 8.0%.
   - قابل للرجوع الفوري عبر راية `'common_text_filter_mode': 'baseline'`.
3. **كاشف الاستشهاد المنقح (EXP-04 Refined Citation Filter):**
   - استبعاد التواريخ واللوائح وأرقام المواد من وسوم الاستشهاد (0.0% استشهاد زائف بالسنوات).
   - دعم التوثيق متعدد المؤلفين بنظام APA.
   - قابل للرجوع الفوري عبر راية `'citation_filter_mode': 'baseline'`.
4. **تأكيد رفض مقترح EXP-02:** الحفاظ التام على عتبة TF-IDF (0.40) لمنع الإيجابيات الكاذبة.
