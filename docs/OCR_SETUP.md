# دليل التثبيت والتشغيل المحلي لمحرك التعرف الضوئي على الحروف (Arabic OCR Offline Deployment Guide)
## Arabic Academic Plagiarism Detector — Release v1.0.0-rc2

---

### 1. الحالة التشغيلية الحالية (Current Runtime State)

- **حالة محرك Tesseract:** مثبت ومتاح محلياً (`C:\Program Files\Tesseract-OCR\tesseract.exe`).
- **حزم اللغات المتاحة حالياً:** `eng`, `osd`.
- **حزمة اللغة العربية (`ara.traineddata`):** **غير متوفرة حالياً (ARABIC OCR LANGUAGE DATA REQUIRED)**.
- **التصنيف الرسمي للمكون:** **`OPTIONAL COMPONENT UNAVAILABLE FOR ARABIC`**.
- **أثر الغياب على المنظومة:** تستمر المنظومة في العمل بكفاءة تامة بنسبة 100% لفحص المستندات الرقمية (PDF, DOCX, TXT)، بينما تُحجب معالجة الصفحات الممسوحة ضوئياً كصور حتى يتم توفير ملف اللغة محلياً.

---

### 2. إجراءات التثبيت اليدوي في البيئات المعزولة (Manual Air-Gapped Installation Protocol)

نظراً لأن المنظومة تعمل في بيئة معزولة تماماً عن شبكة الإنترنت (Air-Gapped Environment)، **يُحظر تماماً أي تنزيل تلقائي**. يتم تفعيل التعرف على النصوص العربية باتباع الخطوات اليدوية التالية:

1. **الحصول على ملف اللغة العربية:**
   - نقل ملف `ara.traineddata` (الإصدار المتوافق مع Tesseract 5.x / Tessdata Fast أو Best) عبر وحدة تخزين وسائط خارجية آمنة ومفحوصة أمنياً.
2. **نسخ الملف إلى مسار التثبيت المحلي:**
   - نسخ `ara.traineddata` إلى المسار التالي على خادم التطبيق:
     ```
     C:\Program Files\Tesseract-OCR\tessdata\ara.traineddata
     ```
3. **التحقق من صحة التثبيت:**
   - فتح سطر الأوامر (PowerShell) وتشغيل:
     ```powershell
     tesseract --list-langs
     ```
   - التأكد من ظهور `ara` ضمن قائمة اللغات المتاحة (`ara`, `eng`, `osd`).
4. **إعادة تشغيل خدمة التطبيق:**
   - فور توفر الملف، يتعرف نظام فحص صحة المكونات (`system_health_service`) تلقائياً على توفر محرك OCR للغة العربية.

---

### 3. ضوابط الأمان وعزل الموارد (OCR Resource & Safety Guards)

- **قفل العمليات المشترك (Cross-Process File Lock):** يضمن قيد `MAX_CONCURRENT_OCR_JOBS = 1` تشغيل عملية Tesseract واحدة فقط في نفس اللحظة عبر كامل الخادم لمنع استهلاك المعالج والذاكرة.
- **تنظيف الملفات المؤقتة (Temporary File Cleanup):** يتم حذف صور الصفحات المستخرجة مؤقتاً فور انتهاء عملية التعرف الضوئي سواء نجحت العملية أو فشلت.
- **الإخفاق الآمن (Fail-Closed Safety):** تعطل معالجة صفحة ممسوحة ضوئياً لا يفسد بيانات البحث، ولا يُنشئ تقريراً نهائياً مشوهاً، ويحرر القفل فورياً.
