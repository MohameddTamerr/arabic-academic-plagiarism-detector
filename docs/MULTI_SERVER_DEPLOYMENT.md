# دليل نشر العمال عبر خوادم متعددة على شبكة الوزارة (Multi-Server Deployment Guide)
## Ministry Roadmap — Prompt 3: Distributed Topology

---

## 1. طوبولوجيا النشر الموزع على شبكة الوزارة الداخلية (LAN Multi-Server Topology)

```
                       [ متصفحات المستخدمين / الكليات والأقسام ]
                                          │
                                          v
                   [ خوادم الواجهة والتطبيق (App / API Servers) ]
                     - استقبال طلبات الرفع والتحكيم
                     - إدراج المهام في طابور queue_jobs
                                          │
                                          ├──────────────────────────────┐
                                          v                              v
                [ خادم قاعدة البيانات المشترك ]                [ خزانة التخزين المشتركة CAS ]
                 - PostgreSQL (الهدف الوزاري)                  - Network Share / NFS / SMB / MinIO
                 - جداول المهام والمستخدمين والمراجع            - storage/documents/ab/cd/<hash>/
                                          │                              │
                    ┌─────────────────────┼──────────────────────────────┤
                    v                     v                              v
           [ خادم عمال الفحص 1 ]    [ خادم عمال الفحص 2 ]         [ خادم عمال OCR ]
           (Worker Server A)        (Worker Server B)             (Worker Server C)
           - فحص نصوص وفهارس        - فحص نصوص وفهارس             - استخراج ومعالجة صور
```

## 2. قواعد استقلال البيئة والخوادم (Multi-Machine Invariants)

1. **حظر الاعتماد على المسارات المحلية المطلقة (No Local Absolute Paths in DB):**
   - تخزين مسارات الملفات كمفاتيح نسبية موجهة بالبصمة `documents/ab/cd/<sha256>/content.bin` أو معرفات CAS.
   - حظر تمرير مسارات `C:\...` في حقول المعالجة كمعرفات حصرية.
2. **استقلالية المعرفات (Independent Process Identifiers):**
   - اعتماد معرف العامل `worker_id` الذي يحوي اسم الخادم ورمز الإقلاع العشوائي لمنع أي تصادم بين أجهزة مختلفة تحمل نفس الـ PID.
3. **مزامنة التوقيت المؤسسي (NTP Time Synchronization):**
   - إلزام جميع خوادم الوزارة بالمزامنة مع خادم توقيت داخلي موحد (NTP) لضمان دقة انتهاء عقود الإيجار ونبضات القلب.
