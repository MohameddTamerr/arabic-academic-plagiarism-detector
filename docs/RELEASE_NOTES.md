### 2. المكونات والميزات الرئيسية المعتمدة (Core Verified Capabilities)

1. **محرك الفحص المعجمي المقوى (Production Detector):**
   - كشف النسخ الحرفي والمعدل عبر Shingles ($k=5$) ومعامل جاكارد ($\ge 0.40$).
   - كشف إعادة الصياغة المعجمية عبر TF-IDF والتشابه الجيبي ($\ge 0.40$).
   - كشف وتوثيق الاستشهادات الأكاديمية بالأقواس وعلامات التنصيص ونظام APA.
2. **حوكمة المراجع والأرشفة الموثقة (Reference Corpus Governance):**
   - إصدارات تاريخية مرقمة للمراجع المرجعية مع بصمة تجزئة SHA-256 لكشف التلاعب.
   - التحقق الدوري التلقائي من سلامة الفهرس قبل إطلاق عمليات الفحص.
3. **نظام المهام المتزامن والتعافي التلقائي (Job Management & Concurrency):**
   - طابور مهام متين مبني على SQLite بنمط المعاملات الفورية `BEGIN IMMEDIATE`.
   - قفل عتادي عبر العمليات لمعالجة الـ OCR النسبي (`MAX_CONCURRENT_OCR_JOBS = 1`).
   - استرداد تلقائي للمهام العالقة بعد انقطاع الكهرباء أو إعادة تشغيل الخادم.
4. **الأمان وعزل البيانات والتعافي (Security & Air-Gapped Operation):**
   - تشفير كلمات المرور باستخدام `bcrypt` (12 rounds) مع ترقية تلقائية للهاش القديم.
   - حماية كاملة ضد هجمات التخمين، وحقن المسارات، وملفات ZIP الملغومة.
   - تشغيل محلي 100% بدون إنترنت ودون أي إرسال للبيانات للخارج.
   - منظومة نسخ احتياطي متكاملة مع استعادة مشروطة وفحص سلامة مسبق.
