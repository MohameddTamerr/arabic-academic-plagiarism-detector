# المعمارية الشاملة لمنظومة كاشف السرقات العلمية الأكاديمي (End-to-End System Architecture)
## منظومة كاشف السرقات العلمية الأكاديمي للنصوص العربية — الإصدار v1.4.0-rc

---

## 1. المخطط المعماري الشامل للطبقات (Layered Architecture Diagram)

```
===================================================================================
1. طبقة الواجهات والتحكم (Presentation & REST API Tier)
   - واجهات الويب الآمنة (HTML5 / Vanilla CSS / Responsive Dark & Light Themes)
   - نقاط نهاية API المحمية بنظام الأدوار والصلاحيات الصارم (RBAC Matrix)
   - حماية CSRF، إبطال الجلسات عبر session_version، وعزل تام للمسارات الداخلية
===================================================================================
                                      |
                                      v
===================================================================================
2. طبقة الطابور والعمال الموزعين (Distributed Queue & Worker Execution Tier)
   - طابور المهام المعاملاتي الدائم في قاعدة البيانات (`queue_jobs`)
   - حجز ذري بتوكنات أمان عشوائية (`claim_token`) وعقود إيجار مؤقتة (`leases`)
   - نبضات قلب دورية (`heartbeats`)، استرداد تلقائي بعد الانهيار، وعدالة الأقسام
===================================================================================
                                      |
                                      v
===================================================================================
3. طبقة مسار الفحص والاسترجاع العلمي (Scientific Detection & Retrieval Pipeline)
   - استخراج وتطبيع النصوص العربية الصارم (`Arabic Normalizer 1.0`)
   - الفهرس المقلوب ثنائي المرحلة (`Dual-Channel Two-Stage Inverted Retrieval`)
   - محرك المطابقة المزدوج (`Shingle-Jaccard 1.4` + `TF-IDF Cosine Matcher`)
   - كاشف الاستشهادات الدقيق وتصفية العبارات الشائعة وحيل التلاعب
===================================================================================
                                      |
                                      v
===================================================================================
4. طبقة التخزين المتصل بالمحتوى والموثوقية (CAS Storage & Tamper-Evidence Tier)
   - تخزين الوثائق المرجعية والأبحاث المشفرة بالبصمات (`SHA-256 CAS`)
   - كشف التلاعب الفوري وعدم التطابق (`Fail-Closed on Hash Mismatch`)
   - لقطات التقارير المعتمدة غير القابلة للتعديل (`Tamper-Evident Canonical Hash`)
   - سجل التدقيق غير القابل للإلغاء (`Append-Only Audit Trail`)
===================================================================================
```

## 2. مصفوفة تدفق العمليات للفحص الأكاديمي (Scan Workflow Pipeline)

1. **إيداع البحث (Submission):** رفع الوثيقة -> فحص بنيوي -> توليد بصمة المحتوى SHA-256 -> حفظ في مخزن CAS -> إنشاء مهمة في طابور `queue_jobs`.
2. **سحب المهمة (Claim):** سحب ذري بواسطة عامل متاح -> تخصيص توكن حماية فريد -> بدء نبضات القلب الدورية.
3. **الاسترجاع المرشح (Candidate Retrieval):** استخراج الشنغلز والكلمات الدلالية -> استعلام الفهرس المرجعي المثبت -> تصفية أفضل 50 مرجعاً مرشحاً ($K \le 50$).
4. **المطابقة الدقيقة والتحليل (Detailed Matching):** فحص التطابق اللفظي الشنقلي ومطابقة المتجهات -> كشف وتصنيف الاستشهادات -> استبعاد العبارات الشائعة -> حساب النسبة المئوية.
5. **بناء وتثبيت التقرير (Report Finalization):** بناء التقرير بصيغة JSON القانونية -> حساب بصمة السلامة SHA-256 -> حفظ اللقطة المعتمدة -> توثيق الحدث في سجل التدقيق -> تحديث حالة المهمة كـ `completed`.
