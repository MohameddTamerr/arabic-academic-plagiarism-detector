## Repository and checkpoint investigation

Reviewed [Hamed1Hamed/AI_Generated_Text_Detector](https://github.com/Hamed1Hamed/AI_Generated_Text_Detector) `main` commit `16bb574975401319549be0c0f9ae1f322ae158e7` and the associated [paper](https://www.mdpi.com/2078-2489/15/7/419). The repository names these base encoders: `xlm-roberta-base`, `aubmindlab/bert-base-arabertv2`, `aubmindlab/araelectra-base-discriminator`, and `bert-base-multilingual-cased`. These are **base architectures**, not proof that any local weights classify AI writing.

The [results index](https://github.com/Hamed1Hamed/AI_Generated_Text_Detector/blob/main/Experiments%20Details%20and%20Detection%20Models/Results.txt) claims six downloadable checkpoint/result archives: Custom Max dediacritized, Custom Max with diacritics, Custom Plus dediacritized, Custom Plus, diacritized custom, and religious. The author states each archive includes models for the applicable experiments, but its contents, per-architecture completeness, fine-tuned weights, version and hashes were not verified: the listed `img-cdn.filefactory.com` host returned `No such host is known` from this environment. No archives were downloaded. The local model inventory contains multilingual E5 only, a retrieval embedder, not this classifier.

The [source](https://github.com/Hamed1Hamed/AI_Generated_Text_Detector/blob/main/Classifier.py) defines a transformer encoder and custom `dense` + dropout + `out_proj` head, uses the first-token hidden state, emits one logit, and evaluates with sigmoid. It saves a whole `CustomModel.state_dict`; a standard `AutoModelForSequenceClassification` head is not interchangeable. Its [dataset loader](https://github.com/Hamed1Hamed/AI_Generated_Text_Detector/blob/main/ClassifierDataset.py) uses local examples' `label` values and truncates/pads to 512 tokens. The [evaluator](https://github.com/Hamed1Hamed/AI_Generated_Text_Detector/blob/main/Evaluator.py) displays confusion-matrix classes in order `AI-generated`, `Human-written`, suggesting index 0 = AI and index 1 = human. This is a source-code display convention, **not an independently verified dataset-label mapping or checkpoint-specific proof**. Confirm the dataset creation/label provenance and exact checkpoint before assigning semantic labels; the adapter requires an explicit mapping and evidence and does not assume the direction.

The code repository API exposes no license and the repository tree contains no LICENSE file. The research paper's article license and public checkpoint links do not by themselves grant model or source-code redistribution or institutional use. Obtain a written, version-specific grant from rights holders and verify the underlying encoder/tokenizer license separately. No such grant was found. AIRABIC's [repository](https://github.com/Hamed1Hamed/AIRABIC) declares CC BY 4.0 but also describes a ShareAlike condition inconsistent with that license name; original books/news rights, intended use, dataset independence and provenance require further review. It is used in the paper and therefore cannot be presumed independent for evaluation of those trained models. No dataset was acquired or evaluated.

## Preprocessing

The paper investigates diacritics and reports effects varying by model and experimental condition. Its [Diacritics-Free branch](https://github.com/Hamed1Hamed/AI_Generated_Text_Detector/blob/Diacritics-Free/ClassifierDataset.py) removes characters U+064B through U+065E inclusive. The research adapter implements exactly that option and separately supports original text. The option must match the specific checkpoint's training setup; original paragraph text and page reference are preserved. There is no aggressive plagiarism normalization and no automatic inference of the correct setting. No original-versus-dediacritized accuracy comparison was possible.

## Adapter and research evaluation

`plagiarism_detector/ai_detection/pretrained_research.py` lazily constructs the source-compatible encoder and head from local config, requires local tokenizer files, uses `local_files_only=True`/`trust_remote_code=False`, checks caller-provided checkpoint SHA-256, loads CPU state with `torch.load(..., weights_only=True)` and `strict=True`, and performs bounded batches in inference mode. It returns an **uncalibrated class-1 sigmoid score**, explicit caller-supplied label mapping, original text/page/paragraph metadata, preprocessing mode and truncation flag. It does not provide human/AI classifications or document percentages. Errors are surfaced as `ResearchAdapterError`; no partial score list is returned on failure. The hash and strict state shape checks cannot prove the checkpoint is genuinely fine-tuned, licensed, compatible with the tokenizer's training revision, or scientifically validated. Tokenizer/config artifacts are local but not independently hash-pinned by this adapter; their identity must be recorded and checked externally. `weights_only=True` reduces pickle risk but does not make unknown artifacts trustworthy.

`tools/evaluate_pretrained_research.py` evaluates an explicitly authorized, independently labeled JSON array of `text` and `provenance_label` (`HUMAN` or `AI_GENERATED`), with a curator-attested local permission/independence manifest. It calculates aggregate binary metrics and uncalibrated Brier score; it does not inspect private content in output. The attestation is not independent evidence of rights, labels or separation from training. Fix the threshold on a separate validation set before evaluating a held-out set; the tool does not enforce one-time access or perform subgroup analysis. Example after separate rights/provenance review and obtaining matching local assets:

```powershell
python -m tools.evaluate_pretrained_research --model-dir LOCAL_MODEL_DIR --checkpoint LOCAL_CHECKPOINT.pt --checkpoint-sha256 TRUSTED_SHA256 --data AUTHORIZED_TEST.json --manifest AUTHORIZED_TEST_MANIFEST.json --class-one HUMAN --label-mapping-evidence VERIFIED_EVIDENCE_REFERENCE --preprocessing original --ai-threshold VALIDATION_THRESHOLD
```

The class-one argument shown is only the upstream plot convention, **not a verified checkpoint mapping**; use it only after checking actual provenance. Manifest fields: `dataset_use_authorized`, `model_use_authorized`, `independent_evaluation_attested` must be true; `dataset_authorization_reference` and `model_authorization_reference` must be nonempty strings. This standalone command accepts no URL and never downloads assets.
