# سجل التغييرات الرقابي لمحرك الفحص الأكاديمي (Detector Change Registry & Traceability)
## Release v1.0.0-rc2 — Change Control Log

All production changes in `v1.0.0-rc2` are strictly traceable to empirical Phase 19 evidence and are isolated behind configuration feature flags.

---

### Change Registry Table

| Change ID | Source Experiment | Affected Module | Old Behavior (RC1) | New Behavior (RC2) | Rationale & Expected Benefit | Known Risks & Mitigation | Rollback Method | Verification Test | Gate Decision |
|:---:|:---:|:---|:---|:---|:---|:---|:---|:---|:---:|
| **CHG-01** | **EXP-01** | `plagiarism_detector.detection.candidate_retriever` | Single-channel word-token inverted index (`candidate_retrieval_mode = 'baseline'`). | Dual-channel inverted index (Word Tokens + Char 3-grams) when `candidate_retrieval_mode = 'dual_channel'`. | Increases candidate retrieval Recall@10 from 52.8% to 93.1% on holdout, capturing morphologically varied passages. | Slight latency increase (+0.18ms); mitigated by capped candidate retrieval ($top\_k=50$). | Set `'candidate_retrieval_mode': 'baseline'` in settings or config. | `test_dual_channel_retrieval_improvement`, `test_retrieval_mode_rollback` | **ACCEPTED** |
| **CHG-02** | **EXP-03** | `plagiarism_detector.filters.common_phrases` | Paragraph-level boilerplate dictionary suppression (`common_text_filter_mode = 'baseline'`). | Span-level institutional phrase suppression (`common_text_filter_mode = 'span_level'`). | Reduces false-overlap rate on institutional boilerplate from 44.0% to 8.0% while preserving 100% of substantive copied spans. | Risk of over-suppression; mitigated by strict span-slicing preventing suppression of substantive content. | Set `'common_text_filter_mode': 'baseline'` in settings or config. | `test_span_level_common_text_safety`, `test_common_text_rollback` | **ACCEPTED** |
| **CHG-03** | **EXP-04** | `plagiarism_detector.citations.citation_detector` | Basic APA/IEEE regex with 3.66% false citations on dates/laws (`citation_filter_mode = 'baseline'`). | Refined Arabic citation parser excluding isolated dates and statute numbers (`citation_filter_mode = 'refined'`). | Eliminates false citations on dates/law articles (0.0% false citation rate on dates) while supporting multi-author APA. | Potential regression on unstandardized citation formats; mitigated by fallback regex. | Set `'citation_filter_mode': 'baseline'` in settings or config. | `test_refined_citation_filter_accuracy`, `test_citation_filter_rollback` | **ACCEPTED** |
| **CHG-04** | **EXP-02** | `plagiarism_detector.detection.tfidf_matcher` | High threshold TF-IDF ($0.40$). | Standalone Char TF-IDF with low threshold ($0.30$). | Proposal to improve paraphrase recall. | **REJECTED**: Caused 60.0% false-positive rate on domain hard negatives. | **NOT APPLIED** — Baseline threshold ($0.40$) strictly preserved. | `test_paraphrase_rejection_preserved` | **REJECTED** |
| **CHG-05** | **RC2 Versioning** | `app.versioning`, `plagiarism_detector.reporting.report_builder` | Static version strings without engine parameter snapshot in report. | Version registry bumped to App `2.5.0` / Engine `1.3.0` with full configuration & component version snapshot in report metadata. | Ensures 100% report reproducibility and audit compliance across releases. | None; backward compatible with RC1 reports. | Version constants rollback. | `test_report_reproducibility_snapshot` | **ACCEPTED** |
